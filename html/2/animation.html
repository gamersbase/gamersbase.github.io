[핵심요약] CSS3 애니메이션 (Animation)

1. 기본 개념

  • 애니메이션: 시간에 따른 위치, 크기, 색상, 회전 등의 변화[cite: 1]
  • JavaScript 없이 CSS만으로 구현 가능[cite: 1]
  • 키 프레임 (Key Frame): 주요 변화 시점 지정 (0%, 25%, 50%...)[cite: 1]
  • 트위닝 (Tweening): 중간 프레임을 브라우저가 자동 생성[cite: 1]

2. 핵심 속성 설명

  • @keyframes: 애니메이션 프레임 정의[cite: 1]
  • animation-name: 실행할 키프레임 이름[cite: 1]
  • animation-duration: 1회 실행 시간 (예: 5s)[cite: 1]
  • animation-iteration-count: 반복 횟수 (예: infinite)[cite: 1]

3. Transition vs Animation

  • Transition: :hover 등 이벤트에 의한 상태 변화 시에만 실행[cite: 1]
  • Animation: 이벤트 없이도 자동/연속 실행 가능[cite: 1]

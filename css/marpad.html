Margin vs Padding

요소의 바깥 여백(margin)과 안쪽 여백(padding)의 차이

📦 Margin — 요소 바깥 여백

Box A
↕ margin-top: 24px (바깥 간격)
Box B
Margin은 요소와 요소 사이의 거리입니다.
배경색은 적용되지 않으며 투명합니다.

🗂 Padding — 요소 안쪽 여백

↔ padding: 28px
콘텐츠
Padding은 테두리와 콘텐츠 사이 공간입니다.
배경색이 padding 영역까지 채워집니다.

⚡ 단축 속성 (shorthand)

값 개수코드의미
1개margin: 10px상하좌우 전체
2개margin: 10px 20px상하 / 좌우
3개margin: 10px 20px 5px상 / 좌우 / 하
4개margin: 10px 20px 5px 0상 / 우 / 하 / 좌

padding 단축 속성도 동일한 규칙 적용

🔍 차이점 비교

항목MarginPadding

🎯 CSS Box Model — 전체 구조

Content
Padding (노란색)
Border (주황 테두리)
Margin (빨간색)
Content → Padding → Border → Margin 순서로 바깥으로 확장됩니다. box-sizing: border-box 를 쓰면 padding과 border가 width 안에 포함됩니다.

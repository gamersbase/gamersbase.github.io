기본 선택자
요소, 클래스, ID 등 가장 기초적인 선택자
* 기본
전체 선택자 — 페이지의 모든 요소를 선택합니다.
* { box-sizing: border-box; margin: 0; }
element 기본
타입(태그) 선택자 — 특정 HTML 요소를 모두 선택합니다.
p { line-height: 1.7; } h1 { font-size: 2rem; } ul { list-style: none; }
.class 기본
클래스 선택자 — 동일한 class 속성을 가진 요소들을 선택합니다.
.card { border-radius: 12px; } .card.active { /* 다중 클래스 */ background: blue; }
#id 기본
ID 선택자 — 고유한 id 속성을 가진 단 하나의 요소를 선택합니다.
#header { position: sticky; } #nav { width: 240px; }
A, B, C 기본
그룹 선택자 — 여러 선택자를 쉼표로 묶어 같은 스타일을 동시에 적용합니다.
h1, h2, h3, h4 { font-weight: 700; line-height: 1.2; }
⟶
결합자 (Combinators)
요소 간의 관계를 기반으로 선택하는 선택자
A B 결합자
자손 결합자 — A 내부의 모든 B 요소(깊이 무관)를 선택합니다.
nav a { color: inherit; } .card p { font-size: 14px; }

<div> — 부모

↳ <p> — 자손 (선택됨)

↳ <span> 안의 <p>도 선택됨

A > B 결합자
자식 결합자 — A의 직접적인 자식 B만 선택합니다(손자 제외).
ul > li { padding: 8px 0; } .nav > a { font-weight: 600; }
  • 직접 자식 li (선택됨)
  • 직접 자식 li (선택됨)
    • 중첩 li (선택 안 됨)
A + B 결합자
인접 형제 결합자 — A 바로 다음에 오는 형제 B 하나만 선택합니다.
h2 + p { margin-top: 8px; } input + label { cursor: pointer; }
<h2> 제목
h2 + div — 선택됨 ✓
그 다음 형제 — 선택 안 됨
A ~ B 결합자
일반 형제 결합자 — A 이후에 오는 모든 형제 B를 선택합니다.
h2 ~ p { color: #666; } .active ~ li { opacity: 0.5; }

[ ]
속성 선택자 (Attribute)
HTML 속성 값을 기준으로 선택하는 선택자
[attr] 속성
해당 속성이 존재하는 요소를 선택합니다 (값 무관).
[disabled] { opacity: 0.4; } [data-tooltip] { cursor: help; }
[attr="val"] 속성
속성 값이 정확히 일치하는 요소를 선택합니다.
input[type="text"] { ... } a[href="#"] { pointer-events: none; }
[attr~="val"] 속성
공백으로 구분된 속성 값 목록 중 해당 단어를 포함하는 요소를 선택합니다.
[class~="active"] { font-weight: bold; } /* class="btn active large" → 선택됨 */
[attr^="val"] 속성
속성 값이 특정 문자열로 시작하는 요소를 선택합니다.
a[href^="https"] { color: green; } [class^="icon-"] { display: inline-block; }
[attr$="val"] 속성
속성 값이 특정 문자열로 끝나는 요소를 선택합니다.
a[href$=".pdf"]::after { content: " 📄"; } img[src$=".webp"] { ... }
[attr*="val"] 속성
속성 값 어디든 해당 문자열이 포함된 요소를 선택합니다.
a[href*="github"] { color: #6e40c9; } [data-id*="user"] { ... }
[attr|="val"] 속성
값이 정확히 일치하거나, 해당 값 뒤에 하이픈(-)이 오는 요소를 선택합니다. 주로 언어 코드에 사용.
[lang|="en"] { ... } /* lang="en" 또는 lang="en-US" 선택 */
[attr="val" i] 속성
대소문자를 구분하지 않고 속성 값을 비교합니다.
input[type="text" i] { ... } /* type="TEXT" type="Text" 도 선택됨 */
:
가상 클래스 (Pseudo-class)
요소의 특정 상태나 위치를 기반으로 선택하는 선택자
:hover 가상 클래스
마우스 커서가 올라간 상태의 요소를 선택합니다.
a:hover { color: #6c63ff; } .btn:hover { transform: translateY(-2px); }

← 여기에 마우스를 올려보세요

:focus 가상 클래스
키보드 포커스를 받은 요소를 선택합니다.
input:focus { border-color: #6c63ff; outline: none; }
:active 가상 클래스
클릭되어 활성화된 상태의 요소를 선택합니다.
.btn:active { transform: scale(0.97); opacity: 0.8; }
:visited 가상 클래스
이미 방문한 링크 요소를 선택합니다.
a:visited { color: #8b5cf6; }
:link 가상 클래스
아직 방문하지 않은 링크 요소를 선택합니다.
a:link { color: #3b82f6; }
:first-child 가상 클래스
부모의 첫 번째 자식 요소를 선택합니다.
li:first-child { font-weight: 700; color: #6c63ff; }
  • 첫 번째 항목 (선택됨)
  • 두 번째 항목
  • 세 번째 항목
:last-child 가상 클래스
부모의 마지막 자식 요소를 선택합니다.
li:last-child { border-bottom: none; }
  • 첫 번째 항목
  • 두 번째 항목
  • 마지막 항목 (선택됨)
:nth-child(n) 가상 클래스
n번째 자식을 선택합니다. 수식(2n+1), 키워드(even/odd)도 사용 가능합니다.
tr:nth-child(even) { background: #f5f5f5; } li:nth-child(3n+1) { color: red; }
  • 1번 (홀수 — 선택됨)
  • 2번
  • 3번 (홀수 — 선택됨)
  • 4번
  • 5번 (홀수 — 선택됨)
:nth-last-child(n) 가상 클래스
뒤에서 n번째 자식을 선택합니다.
li:nth-last-child(2) { color: orange; } /* 마지막에서 2번째 li */
:first-of-type 가상 클래스
같은 타입 요소 중 첫 번째를 선택합니다.
p:first-of-type { font-size: 1.1em; font-weight: 500; }
:last-of-type 가상 클래스
같은 타입 요소 중 마지막을 선택합니다.
p:last-of-type { margin-bottom: 0; }
:nth-of-type(n) 가상 클래스
같은 타입 요소 중 n번째를 선택합니다.
img:nth-of-type(2) { float: right; }
:only-child 가상 클래스
부모의 유일한 자식인 요소를 선택합니다.
li:only-child { list-style: none; }
:only-of-type 가상 클래스
부모 안에서 해당 타입이 유일한 요소를 선택합니다.
img:only-of-type { display: block; margin: 0 auto; }
:not(selector) 가상 클래스
해당 선택자에 매칭되지 않는 요소를 선택합니다 (부정 선택자).
input:not([type="submit"]) { border: 1px solid #ccc; } li:not(:last-child) { border-bottom: 1px solid #eee; }
:checked 가상 클래스
체크된 checkbox/radio 요소를 선택합니다.
input:checked + label { color: #6c63ff; font-weight: 600; }
:disabled 가상 클래스
비활성화된 폼 요소를 선택합니다.
input:disabled { opacity: 0.4; cursor: not-allowed; }
:enabled 가상 클래스
활성화된 폼 요소를 선택합니다.
input:enabled:focus { box-shadow: 0 0 0 3px rgba(108,99,255,.3); }
:empty 가상 클래스
자식 요소나 텍스트가 전혀 없는 요소를 선택합니다.
td:empty { background: #f9f9f9; } p:empty { display: none; }
:root 가상 클래스
문서의 최상위 요소(HTML에서는 <html>)를 선택합니다. CSS 변수 선언에 주로 사용.
:root { --primary: #6c63ff; --font-size: 16px; }
:is() / :where() 가상 클래스
여러 선택자 그룹을 간결하게 작성합니다. :where()는 명시도가 0입니다.
:is(h1, h2, h3) a { ... } :where(header, footer) p { margin: 0; }
:has() 가상 클래스
특정 자식을 가진 부모 요소를 선택합니다 (부모 선택자, CSS4).
div:has(> img) { display: grid; } form:has(:invalid) { border-color: red; }
:target 가상 클래스
URL 해시(#)와 id가 일치하는 요소를 선택합니다.
section:target { outline: 2px solid #6c63ff; scroll-margin-top: 80px; }
:lang(code) 가상 클래스
특정 언어 속성을 가진 요소를 선택합니다.
:lang(ko) { word-break: keep-all; } :lang(en) { hyphens: auto; }
:focus-within 가상 클래스
요소 자신 또는 자손이 포커스를 받은 경우 부모를 선택합니다.
form:focus-within { box-shadow: 0 0 0 3px rgba(99,102,241,.3); }
:placeholder-shown 가상 클래스
placeholder가 표시 중인(아직 입력되지 않은) input을 선택합니다.
input:placeholder-shown + label { top: 50%; font-size: 16px; }
:valid / :invalid 가상 클래스
HTML5 유효성 검사 통과/실패 상태의 폼 요소를 선택합니다.
input:valid { border-color: green; } input:invalid { border-color: red; }
::
가상 요소 (Pseudo-element)
요소의 특정 부분을 스타일링하는 선택자 (콜론 두 개)
::before 가상 요소
요소의 내용 앞에 가상의 콘텐츠를 삽입합니다. content 속성 필수.
.required::before { content: "* "; color: red; } .quote::before { content: """; }
::after 가상 요소
요소의 내용 뒤에 가상의 콘텐츠를 삽입합니다.
a[href^="https"]::after { content: " ↗"; font-size: 0.8em; } .clearfix::after { content: ""; display: table; clear: both; }
::first-line 가상 요소
블록 요소의 첫 번째 줄 텍스트를 선택합니다.
p::first-line { font-weight: 600; letter-spacing: 0.05em; }
::first-letter 가상 요소
블록 요소의 첫 번째 글자를 선택합니다. 드롭캡에 활용.
p::first-letter { float: left; font-size: 3em; line-height: 0.8; margin-right: 8px; }
::selection 가상 요소
사용자가 드래그하여 선택한 텍스트를 스타일링합니다.
::selection { background: #6c63ff; color: white; }
::placeholder 가상 요소
input/textarea의 placeholder 텍스트를 스타일링합니다.
input::placeholder { color: #aaa; font-style: italic; }
::marker 가상 요소
리스트 아이템의 불릿/번호를 스타일링합니다.
li::marker { color: #6c63ff; font-size: 1.2em; }
::backdrop 가상 요소
<dialog>나 fullscreen 요소 뒤의 배경 레이어를 스타일링합니다.
dialog::backdrop { background: rgba(0,0,0,0.5); backdrop-filter: blur(4px); }

CSS Position 가이드 position: fixed — 이 헤더가 실제 데모입니다

CSS position 5가지 완전 이해

static · relative · absolute · fixed · sticky — 각각의 동작 원리와 사용 시점

position: static

Static — 기본값

position 을 따로 지정하지 않으면 모든 요소가 static입니다

▸ 데모 — 일반 흐름(normal flow)대로 순서대로 배치

Box 1
Box 2
Box 3
Box 4 (다음 줄)
top / right / bottom / left / z-index 속성이 모두 무시됩니다. 레이아웃의 기준점 역할만 하며, 다른 position 값으로 바꾸기 전까지는 아무것도 이동하지 않습니다.
position: relative

Relative — 원래 자리 기준 이동

원래 위치에서 top / left 만큼 시각적으로 이동. 문서 흐름 속 자리는 유지

▸ 데모 — 가운데 박스가 top: 14px; left: 20px 만큼 이동됨

Box A
Box B
top:14px left:20px
Box C
이동 후에도 원래 자리(Box B의 공간)는 그대로 남아 있어 Box C가 그 옆에 위치합니다. 또한 position: absolute 자식의 기준점(containing block)이 됩니다.
position: absolute

Absolute — 가장 가까운 positioned 조상 기준

문서 흐름에서 완전히 빠져 나와, position이 지정된 가장 가까운 부모를 기준으로 배치

▸ 데모 — 분홍 박스(부모: relative) 의 오른쪽 아래에 배지 배치

부모 요소 position: relative
✦ absolute 배지
bottom:10px right:12px
주의: positioned 조상(relative/absolute/fixed/sticky)이 없으면 <html> 전체가 기준이 됩니다. 툴팁, 드롭다운, 배지 등 특정 위치에 띄우는 UI에 자주 씁니다.
position: fixed

Fixed — 뷰포트(화면) 기준 고정

스크롤해도 화면 상의 위치가 변하지 않음. 이 페이지의 상단 헤더가 실제 예제

이 페이지 맨 위 검은 헤더가 바로 position: fixed 예제입니다.
페이지를 스크롤해도 항상 화면 상단에 고정됩니다. top: 0; left: 0; right: 0; 과 함께 z-index 로 다른 요소 위에 올립니다.

▸ 주요 사용 사례

고정 내비게이션 바 플로팅 채팅 버튼 쿠키 배너 모달 오버레이
position: sticky

Sticky — 스크롤 임계점 도달 시 고정

평소엔 relative처럼 흐름 속에 있다가, 지정한 위치(top 등)에 닿으면 fixed처럼 고정

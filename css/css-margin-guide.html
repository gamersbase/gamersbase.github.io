CSS 박스 모델 및 스타일 가이드

1. 경계선 종류 (Border Styles)

border 속성은 요소를 감싸는 테두리입니다. 기본적으로 border: 두께 종류 색상; 형태로 지정하며, border-top처럼 특정 방향만 지정할 수도 있습니다.
Solid
(실선)
Dashed
(파선)
Dotted
(점선)
Double
(이중선)
Mixed
(사방 각각 지정)

2. 여백 (Margin & Padding)

  • Margin (외부 여백): 테두리(Border)의 바깥쪽 공간입니다. 다른 요소와의 간격을 조절할 때 사용합니다.
  • Padding (내부 여백): 테두리(Border)의 안쪽 공간입니다. 콘텐츠와 테두리 사이의 숨통을 트여줄 때 사용합니다.
* 아래 예제에서 노란색 영역은 마진(Margin) 공간이며, 글자 주변의 주황색 공간은 패딩(Padding) 영역입니다.
마진: 사방 30px
패딩: 사방 20px
(노란색 공간이 Margin입니다)

3. 박스 그림자 (Box Shadow)

box-shadow 속성은 요소에 입체감을 주는 그림자 효과입니다.
형식: box-shadow: [X축이동] [Y축이동] [흐림도(Blur)] [확산도(Spread)] [색상] [inset(안쪽그림자 여부)];
기본 그림자
(우하향)
부드러운 그림자
(공중 부양 느낌)
색상 그림자
(네온/무드 효과)
안쪽 그림자
(음각 효과)

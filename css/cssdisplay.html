Block 요소 vs Inline 요소

display 속성이 결정하는 두 가지 렌더링 방식 — 예제와 비교로 완전히 이해하기

Block 요소 Inline 요소 비교표 코드 예제
Block

Block 요소 — 줄 전체를 차지하는 박스

항상 새 줄에서 시작하고, 부모의 너비 100%를 기본으로 차지합니다.

핵심 규칙: Block 요소는 항상 위아래로 쌓입니다. width, height, margin, padding 모두 자유롭게 지정 가능합니다.

▸ 실제 렌더링 모습

<h2> 제목 — Block 요소 (보라색)
<p> 문단 텍스트입니다. Block 요소는 항상 새 줄에서 시작합니다. (초록색)
<div> 범용 컨테이너. 레이아웃 구성에 가장 많이 씁니다. (파란색)
  • <ul> / <li> 목록도 Block 요소입니다 (주황색)
  • 각 항목이 세로로 쌓입니다
<form> 폼 영역 — 입력 요소를 감싸는 Block 컨테이너 (산호색)
<table> 표 — Block처럼 줄을 차지합니다 (회색)

▸ 주요 Block 요소 태그

<div> <p> <h1> ~ <h6> <ul> / <ol> <li> <table> <form> <header> <section> <footer> <article> <aside> <nav> <blockquote> <hr> <pre>
Inline

Inline 요소 — 콘텐츠 크기만큼만 차지하는 박스

텍스트 흐름 안에서 나란히 배치됩니다. 새 줄을 만들지 않습니다.

핵심 규칙: Inline 요소는 텍스트와 함께 흐릅니다. width, height는 지정해도 무시되고, 상하 margin도 제한됩니다.

▸ 실제 렌더링 모습 — 같은 줄에 나란히 배치됨

이 문장에는 <span> 강조 영역이 있고, <a> 링크도 있습니다. 그리고 <strong> 굵은 텍스트와 <em> 기울임 텍스트, <code> 코드 스니펫도 <img> 이미지자리와 함께 <label> 라벨처럼 모두 한 줄 안에 나란히 배치됩니다.

▸ 주요 Inline 요소 태그

<span> <a> <strong> <em> <code> <img> <label> <input> <button> <abbr> <br> <i> / <b> <sup> / <sub> <time> <mark>

비교표 — Block vs Inline

어떤 상황에서 어떤 요소를 써야 할지 한눈에

특성 Block 요소 Inline 요소
줄 바꿈 앞뒤로 자동 줄 바꿈 발생 줄 바꿈 없이 텍스트 흐름에 합류
기본 너비 부모 너비 100%를 차지 콘텐츠 크기만큼만 차지
width / height ✓ 지정 가능 ✗ 무시됨
상하 margin ✓ 완전 적용 ✗ 좌우만 적용
padding 상하좌우 모두 적용 좌우는 적용, 상하는 레이아웃에 영향 없음
자식 요소 Block, Inline 모두 포함 가능 원칙적으로 Inline 요소만 포함
주요 용도 레이아웃 구조, 섹션, 컨테이너 텍스트 내 강조, 링크, 장식
CSS로 전환 display: inline 으로 전환 가능 display: block 으로 전환 가능
inline-block 두 방식의 중간 — 줄에 나란히 있으면서 width/height도 지정 가능 (display: inline-block)

코드 예제

실제 HTML과 CSS로 동작 방식 확인하기

▸ Block 예제

<!-- Block 요소는 세로로 쌓임 -->
<div style="background:#E6F1FB;">
  첫 번째 div
</div>
<div style="background:#EAF3DE;">
  두 번째 div
</div>
<p>이것도 Block 요소입니다</p>

▸ Inline 예제

<!-- Inline 요소는 나란히 배치됨 -->
<p>
  <span>첫 번째</span>
  <span>두 번째</span>
  <a href="#">링크</a>
  <strong>굵게</strong>
  모두 한 줄에 배치됨
</p>

▸ display 속성으로 전환하기

/* span(Inline)을 Block처럼 쓰기 */
span {
  display: block;     /* 이제 줄 전체 차지 */
  width: 200px;
  height: 50px;
}

/* div(Block)를 Inline처럼 쓰기 */
div {
  display: inline;    /* 이제 텍스트 흐름에 합류 */
}

/* 두 방식의 장점만 취하기 */
.button {
  display: inline-block; /* 나란히 + 크기 지정 */
  width: 120px;
  height: 40px;
}

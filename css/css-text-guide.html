HTML/CSS 텍스트 & 색상 속성 완전 가이드

font · text · shadow · direction · decoration · transform · 16진수 색상

① font 속성 (font-family / font-size / font-weight / font-style)

예제 1 — font-family
font-family: Georgia, serif;
세리프 계열 폰트 적용
serif 계열(Georgia)로 지정. 브라우저가 지원하지 않을 때 generic-family(serif)가 대체함.
예제 2 — font-size
font-size: 22px;
큰 글씨
픽셀(px)로 고정 크기 지정. 반응형에는 rem/em 권장. 22px = 기본 16px의 약 1.375배.
예제 3 — font-weight & font-style
font-weight: 300; font-style: italic;
가늘고 기울어진 텍스트
weight 100~900 사이 지정. italic은 기울임 서체, oblique는 강제 기울임.
예제 4 — text-align & line-height
text-align: justify; line-height: 2;
양쪽 정렬 예시. 텍스트가 양쪽 끝을 맞춰 고르게 배치되고 줄 간격이 2배로 넓어집니다.
justify는 양쪽 정렬. line-height: 2는 글자 크기의 2배 줄 간격.

② text-shadow 속성

예제 5 — text-shadow (다중 그림자)
text-shadow: 2px 2px 6px #e74c3c, -1px -1px 3px #f39c12;
텍스트 그림자 효과
형식: x오프셋 y오프셋 흐림반경 색상. 쉼표로 여러 그림자를 겹칠 수 있음. 첫 번째(빨강)는 오른쪽 아래, 두 번째(주황)는 왼쪽 위 방향.

③ letter-spacing & word-spacing 속성

예제 6 — letter-spacing & word-spacing
letter-spacing: 4px; word-spacing: 12px;
글자 간격 단어 간격
letter-spacing: 글자 사이 간격. word-spacing: 단어 사이 공백 크기. 음수값도 가능 (글자를 더 가깝게). 로고·제목 디자인에 자주 활용.

④ text-decoration 속성

예제 7 — text-decoration (underline / line-through / overline)
text-decoration: underline wavy #e74c3c;
물결 밑줄 취소선 윗줄
line: underline | overline | line-through. style: solid | wavy | dotted | dashed | double. color를 별도 지정 가능. CSS3에서 shorthand로 통합됨.

HTML/CSS 텍스트 & 색상 속성 완전 가이드

text-transform · direction · shadow 종합 · 16진수 색상 10가지

⑤ text-transform 속성

예제 8 — text-transform (uppercase / lowercase / capitalize)
text-transform: uppercase | lowercase | capitalize;
hello world → HELLO WORLD
HELLO WORLD → hello world
hello world → Hello World
uppercase: 모두 대문자. lowercase: 모두 소문자. capitalize: 각 단어 첫 글자만 대문자. HTML 원본 텍스트는 변경되지 않으며 CSS 렌더링만 바뀜.

⑥ direction & unicode-bidi 속성

예제 9 — direction: rtl / ltr
direction: rtl; unicode-bidi: bidi-override;
RTL: 오른쪽에서 왼쪽으로 (아랍어·히브리어 방식)
LTR: 왼쪽에서 오른쪽으로 (기본값 — 한국어·영어)
direction: ltr(기본) | rtl. unicode-bidi: bidi-override로 텍스트 방향 강제 지정. 다국어 웹사이트에서 필수 속성.

⑦ text-shadow + box-shadow 종합 예제

예제 10 — 네온 글로우 효과 (text-shadow + box-shadow + 16진수 색상)
text-shadow: 0 0 8px #00d4ff; box-shadow: 0 4px 15px rgba(0,212,255,0.4);
✦ 네온 글로우 텍스트 효과 ✦
text-shadow의 x·y를 0으로 하고 blur만 주면 발광 효과. box-shadow는 컨테이너에 후광 추가. #00d4ff = 밝은 청록색 (R:0, G:212, B:255).

⑧ 16진수(HEX) 색상 10가지 예시

# HEX 코드 미리보기 색상 이름 R / G / B 분해 주요 활용
1 #FF0000 순수 빨강 (Red) R:255 G:0 B:0 경고, 오류, 강조
2 #00FF00 순수 초록 (Lime) R:0 G:255 B:0 성공, 완료 상태
3 #0000FF 순수 파랑 (Blue) R:0 G:0 B:255 링크, 신뢰, 정보
4 #FFFF00 노랑 (Yellow) R:255 G:255 B:0 하이라이트, 주의
5 #FF6B35 주황 (Orange) R:255 G:107 B:53 CTA 버튼, 에너지
6 #2C3E50 다크 네이비 R:44 G:62 B:80 헤더, 배경, 본문
7 #ECF0F1 연회색 (Cloud) R:236 G:240 B:241 배경, 카드 표면
8 #8E44AD 보라 (Purple) R:142 G:68 B:173 프리미엄, 창의성
9 #1ABC9C 청록 (Turquoise) R:26 G:188 B:156 아이콘, 뱃지, 태그
10 #F39C12 황금 (Gold) R:243 G:156 B:18 별점, 경고, 뱃지
16진수 색상 읽는 법:   #RRGGBB — 각 2자리가 R(빨강)·G(초록)·B(파랑)를 16진수(00~FF)로 표현. 3자리 단축형 #RGB도 가능 (#F00 = #FF0000). 대소문자 구분 없음.

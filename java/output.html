📘 JavaScript 출력문 정리

JavaScript에서는 여러 가지 방법으로 사용자에게 데이터를 출력할 수 있습니다. 대표적인 방법은 다음 4가지입니다.

1. 출력 방법 한눈에 보기

방법 사용법 출력 위치 특징
document.write() document.write() HTML 문서 웹 페이지에 직접 출력
innerHTML 요소.innerHTML HTML 요소 특정 요소의 내용을 변경
alert() window.alert() 팝업 창 사용자에게 메시지를 보여줌
console.log() console.log() 개발자 도구 개발 및 디버깅에 사용

2. document.write()

document.write()는 HTML 문서에 직접 내용을 출력하는 방법입니다. 

```

document.write("outPut1:write");
```

결과:

⚠️ 주의: 페이지가 모두 로딩된 후 document.write()를 실행하면 기존 HTML 내용이 모두 지워질 수 있습니다.

3. innerHTML

innerHTML은 HTML 요소 안의 내용을 변경할 때 사용합니다. 

```

document.getElementById("output").innerHTML
= "outPut2:innerHTML";
```

변경되기 전 내용

여기서 getElementById("output")는 id="output"인 HTML 요소를 찾는 역할을 합니다.

4. window.alert()

alert()는 화면에 팝업 창을 띄워 메시지를 보여줍니다. 

```

window.alert("outPut3:alert");
```

실행하면 브라우저에 메시지 창이 나타납니다.

5. console.log()

console.log()는 브라우저의 개발자 도구 콘솔에 값을 출력합니다. 

```

console.log("outPut4:console");
```

결과를 확인하려면 브라우저에서 F12 → Console을 선택합니다.

7. 시험 대비 핵심 정리 ⭐

  • document.write() → HTML 문서에 직접 출력
  • innerHTML → 특정 HTML 요소의 내용을 변경
  • alert() → 팝업 창으로 메시지 출력
  • console.log() → 개발자 도구의 Console에 출력

alert() 📢 팝업으로 알려주기
console.log() 🔧 개발자에게 결과 보여주기

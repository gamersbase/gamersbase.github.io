[핵심요약] 자바스크립트(JavaScript) 개요

1. 웹 기술의 역할 분담

  • HTML: 문서의 구조와 내용 담당
  • CSS: 디자인과 레이아웃 담당
  • JavaScript: 동적 반응과 사용자 동작 담당

2. 자바스크립트 특징 및 역사

  • 개발자: 넷스케이프의 브렌던 아이크
  • 초기명 LiveScript → JavaScript (현재 ECMAScript 표준 사용)
  • 컴파일 과정 없이 실행되는 인터프리터 언어
  • 객체 기반(Object-based) 및 함수형 프로그래밍 지원

3. 자바스크립트 삽입 방법 3가지

  • 외부 JS: <script src="파일명.js"></script>
  • 내부 JS (<head>): <head> 내부 <script> 작성
  • 인라인 JS (<body>): <body> 내 원하는 위치에 <script> 작성
